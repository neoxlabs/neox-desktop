## Highlights

- **Local by default** — optional cloud handoff (LAN / relay / cloud pod)
- **Shadow Git** — message-level rollback of agent file edits
- **OS sandbox** — Seatbelt / bubblewrap class isolation for shell
- **BYOK** — bring your own keys; inspectable provider path
- **Same engine as CLI / SDK** — one `StreamedRunner` production loop
- Editor · terminal · timeline · multi-provider
